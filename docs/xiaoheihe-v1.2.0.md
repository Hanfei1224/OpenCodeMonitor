# 🎉 OpencodeMonitor v1.2.0 更新来了！

> 一款 Windows 桌面悬浮磁贴，实时监控你的 **OpenCode Go** 套餐用量，还顺带把本机的 token 消耗也管起来了。无边框、置顶、可鼠标穿透，挂在屏幕角落不挡事。

---

## 📅 这次更新了什么？

### 1️⃣ 综合采集装置 🔄
以前只统计 OpenCode 一个来源，漏掉的消耗补不回来。现在把本机所有 token 消耗都捞进来了：

- 合并 **opencode 本地库** + **Claude Code 会话记录** 双数据源
- 监测程序没开的时候产生的消耗也不丢，下次启动**自动补全**
- 用量统计口径更全，不再"缺一段"

### 2️⃣ 用量统计窗口大升级 📊
- 月度 **token 日历**：色块深浅一眼看出哪天消耗多
- 没有消耗的月份**自动隐藏**，列表干净不占地方
- 切月份 **0 卡顿、无感切换**（数据提前缓存进内存）
- 窗口位置退出保存，下次打开**原位恢复**

### 3️⃣ 今日 token 统计 📈
- 今日总 / 输入 / 输出 / **缓存 / 缓存率**
- 数值自动缩写：`10k` / `300M` / `1.2B`，不会挤爆卡片
- 数值统一等宽底色块，左对齐、居中，看着整齐

### 4️⃣ 细节体验 ✨
- 不透明度只改窗口底色，控件不再跳动、按钮不再变黑
- 统计窗口启动即是你的强调色，不闪默认色
- 「命中 / 命中率」改名「**缓存 / 缓存率**」，口径更直观
